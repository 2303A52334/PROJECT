# Adult Census Income

This repository contains the Adult Census Income dataset and a Jupyter notebook for analysis.

## Contents
- Adult census Income.ipynb - Notebook with data cleaning, exploration, and modeling.
- Adult census Income.csv/adult.csv - The dataset (Adult Census Income).

## Description
The dataset contains demographic and employment information used to predict whether an individual's income exceeds $50K per year.

## How to use
1. Open the notebook `Adult census Income.ipynb` in Jupyter or VS Code.
2. Ensure you have Python 3.8+ and these packages installed:

```
pip install -r requirements.txt
```

If you don't have a `requirements.txt`, install commonly used packages:

```
pip install pandas numpy scikit-learn matplotlib seaborn jupyterlab
```

3. Run the notebook cells to reproduce the analysis and models.

## Notes
- The dataset file is located at `Adult census Income.csv/adult.csv` relative to the repository root.
